# MarketPlace C2C

MarketPlace is a free C2C listings platform where anyone can post ads to sell secondhand items - electronics, furniture, clothing, and more. Buyers browse listings by category, location, and price, and contact sellers directly via built-in messaging.

Tech Stack: React, TypeScript, CSS Modules, React Hook Form, Supabase (Auth, PostgreSQL, Realtime, Storage), Netlify.
